# InsightIQ

## LLM-Powered Data Analytics Platform

InsightIQ is a full-stack data analytics application that allows users to upload CSV datasets and explore their data using natural-language questions.

It combines **LLM-powered intent interpretation with Python and Pandas-based analysis**, allowing users to interact with datasets without manually writing queries or analysis code.

---

## 🚀 Features

- Upload and analyze CSV datasets
- Automatically profile uploaded datasets
- View dataset dimensions, column types, and missing values
- Ask questions about data using natural language
- Use an LLM to interpret analytical intent
- Convert natural-language questions into structured operations
- Perform deterministic calculations with Pandas
- Filter and group data for analysis
- Visualize grouped results with interactive bar charts
- Automated backend unit testing
